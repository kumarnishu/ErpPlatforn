# Google Cloud Storage building block

`IFileStorage` uploads, downloads, and deletes tenant-scoped objects in a private Google Cloud Storage bucket. Object names are generated by the building block under `tenants/{tenant UUID}/`; the original filename is returned as metadata and is not used as the object key. Download and delete validate that the key belongs to the supplied tenant. `StartResumableUploadAsync` optionally creates a resumable upload session for large files. `CreateDownloadUrlAsync` creates a V4 signed GET URL that expires within 15 minutes.

Register with `services.AddGoogleCloudFileStorage(configuration["GoogleCloudStorage:Bucket"]!)`. Credentials use Google Application Default Credentials. For local development, configure ADC with `gcloud auth application-default login`; in production, attach a workload identity or service account with access limited to the bucket and URL-signing permissions. Keep the bucket private. Persist the returned object key, tenant ID, filename, content type, and size in PostgreSQL. Check tenant authorization in the calling API before starting an upload or issuing a download URL. Both a signed download URL and resumable upload session URI are bearer credentials: anyone holding one can use it while it is valid. Send them only over HTTPS and do not log or persist them.

Add `BuildingBlocks/GoogleStorage/BuildingBlocks.GoogleStorage.csproj` as a project reference to services that need file storage.
